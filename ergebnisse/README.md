# Ergebnisse

Arbeitsergebnisse, die der Aufsichtsrat sehen soll, geordnet nach Meilenstein der Roadmap (`M0/`, `M1/` …). Die Firma
kopiert die Datei hierher oder legt einen relativen Verweis (Symlink) auf die Datei im Repo an. Der Motor zeigt diesen
Ordner im Cowork-Dateibrowser als „Produkt-Ergebnisse“, nur lesbar, am Stand von `main` (Aufsichtsrat, 30.09.2026).

- `M0/` — Gesundheit neu: Methodik-Berichte #95 Hitzebelastung, #96 Aeroallergene, #98 UV-Schädigungen, je als PDF und
  als Seite zum Wirkungsmechanismus (Verweise auf `docs/methodik/`).
